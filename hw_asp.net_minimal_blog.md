https://github.com/arakviel/aspnet-samples/tree/main/AspNet.MinimalApiWithFront – приклад (REST API + front)

Ця домашка на ДВІ зустрічі!

1. Треба зробити дві сутності: пости та категорії. У одного поста, можуть бути багато категорій, одна категорія може бути у багатьох постах.
2. Зробити такі enpdpoints:
   (назви можуть бути іншими, але функціонал має бути таким самим)

- GET posts - список всіх постів (\*пагінація за бажанням)
- GET posts/{id} та posts/{slug} - окремий пост, там де slug- це https://dev.to/livecycle/navigating-docker-with-captains-francesco-ciulla-4pie
- GET posts/{category-name}/ - відфільтрувати пости лише заданої категорії (\*пагінація за бажанням)
- GET categories - список всіх категорій, з лінками на [GET posts/{category-name}/]
- GET posts/add - форма додавання нового поста
- POST posts/add - додавання нового поста із валідацією та обробкою помилок
- POST categories/add - форма додавання нової категорії \*пагінація за бажанням)
- POST categories/edit - форма оновлення категорій із валідацією та обробкою помилок
- POST posts/edit - форма оновлення постів із валідацією та обробкою помилок
- XXX posts/delete - список, з можливістю видалити пост
- XXX categories/delete - список, з можливістю видалити категорію
- GET posts/q?search=XXX - пошук поста, через URL QUERY
- GET about - статичний файл з описом вашого блогу

3. Пости повинні мати картинку!
4. Для цього, потрібно використовувати лише ASP.NET minimal API, статичні файли (мідлварку), маршутизацію, обробку помилок та Results API (за бажанням).
5. Для красоти (або без красоти), можна використовувати любий CSS Framework (наприклад Bootstrap)
